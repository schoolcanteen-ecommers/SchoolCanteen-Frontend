# Laporan Pengembangan Hari Keempat — SchoolCanteen

## Perubahan Hari Keempat

- Mengembangkan dashboard Merchant.
- Mengembangkan dashboard Admin.
- Menambahkan tampilan pengelolaan data merchant dan transaksi.
- Menyempurnakan integrasi student checkout dengan backend.
- Menghubungkan alur pesanan student dengan backend.
- Menambahkan pengelolaan status pesanan.
- Melakukan penyesuaian autentikasi dan role pengguna.
- Menyesuaikan beberapa halaman agar menggunakan data dari backend.
- Melakukan testing terhadap alur utama aplikasi.

## Hasil

Pada Hari Keempat, fitur utama untuk Merchant, Admin, dan Student semakin lengkap. Dashboard pengelolaan serta alur checkout dan order telah terintegrasi dengan backend sehingga proses transaksi menjadi lebih terstruktur.

## Keterangan

Pengembangan dilakukan dengan melanjutkan project SchoolCanteen yang sudah tersedia sebelumnya sesuai ketentuan lomba yang memperbolehkan penggunaan source code/project sebelumnya.
