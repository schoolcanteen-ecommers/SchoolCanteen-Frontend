# Day 5 Development Report

## Integrasi Merchant Finance dan Student Wallet Flow

Pada hari kelima pengerjaan, dilakukan pengembangan lanjutan pada aplikasi SchoolCanteen dengan fokus pada penyempurnaan fitur merchant, transaksi, dan wallet pengguna.

## Perubahan yang Dilakukan

### 1. Integrasi Fitur Merchant Finance
- Menambahkan tampilan pengelolaan keuangan untuk merchant.
- Membuat fitur informasi saldo, transaksi, dan proses penarikan dana.
- Menambahkan komponen withdrawal form untuk mendukung proses pencairan dana merchant.

### 2. Pengembangan Merchant Order & Operational Flow
- Menyempurnakan halaman pesanan merchant.
- Menambahkan integrasi data order merchant.
- Memperbaiki alur pickup dan production management agar lebih sesuai dengan kebutuhan operasional kantin.

### 3. Pengembangan Student Wallet
- Menambahkan fitur wallet untuk pengguna student.
- Membuat komponen top up saldo.
- Menambahkan integrasi API terkait saldo dan transaksi wallet.

### 4. Penyempurnaan API dan Struktur Data
- Menambahkan service API baru untuk:
  - Merchant finance
  - Merchant orders
  - Student wallet
  - Student top up
- Melakukan penyesuaian type data order, wallet, dan withdrawal.

### 5. Penggunaan Base Project Sebelumnya
Sebagian struktur aplikasi menggunakan project dasar yang telah dikembangkan pada tahap sebelumnya sesuai dengan ketentuan lomba yang memperbolehkan penggunaan project lama.

Pada tahap ini dilakukan pengembangan lanjutan, integrasi fitur baru, serta penyesuaian agar seluruh fitur dapat berjalan dalam satu aplikasi SchoolCanteen.

## Hasil Akhir
- Fitur keuangan merchant berhasil ditambahkan.
- Flow order merchant semakin lengkap.
- Student dapat menggunakan fitur wallet dan top up.
- Struktur aplikasi lebih siap untuk pengembangan fitur berikutnya.
