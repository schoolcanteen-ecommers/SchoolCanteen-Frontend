# Laporan Pengembangan Hari Kedua — SchoolCanteen

## Perubahan Hari Kedua

- Melanjutkan pengembangan project SchoolCanteen dari source code yang sudah tersedia sebelumnya.
- Mengembangkan halaman login dan register.
- Mengintegrasikan autentikasi menggunakan Supabase.
- Menambahkan session user dan fitur logout.
- Menambahkan proteksi halaman berdasarkan status login dan role user.
- Menghubungkan autentikasi frontend dengan backend untuk mengambil data user dan role.
- Menambahkan role:
  - Student
  - Merchant
  - Admin
- Mengembangkan halaman katalog Kantin dan Koperasi.
- Menghubungkan sebagian data katalog dengan API backend.
- Mengembangkan halaman detail produk.
- Menambahkan sistem keranjang belanja.
- Menambahkan fungsi tambah produk, jumlah item, subtotal, dan tampilan keranjang.
- Mengembangkan halaman checkout dan pilihan waktu pengambilan pesanan.
- Menyesuaikan navigasi, header, dan layout agar mendukung autentikasi dan role user.
- Menambahkan konfigurasi API dan Supabase pada project.
- Melakukan testing aplikasi dan build untuk memastikan hasil pengembangan dapat berjalan dengan baik.

## Hasil

Pada akhir pengerjaan Hari Kedua, aplikasi sudah dapat menjalankan alur utama seperti melihat katalog, login, pembagian akses berdasarkan role, pengelolaan keranjang, serta checkout dasar. Integrasi Supabase dan backend juga sudah dapat berjalan pada project.

## Keterangan

Pengerjaan Hari Kedua tidak dimulai dari project kosong. Pengembangan menggunakan dan melanjutkan folder/source code SchoolCanteen yang telah tersedia sebelumnya, sesuai ketentuan lomba yang memperbolehkan penggunaan project lama sebagai dasar pengembangan.
