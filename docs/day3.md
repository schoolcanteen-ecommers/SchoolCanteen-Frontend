# Laporan Pengembangan Hari Ketiga — SchoolCanteen

## Perubahan Hari Ketiga

- Melanjutkan pengembangan project SchoolCanteen dari source code yang telah digunakan pada hari sebelumnya.
- Menyempurnakan integrasi commerce dengan backend.
- Mengembangkan tampilan dashboard Student.
- Menyempurnakan alur keranjang dan checkout.
- Menambahkan halaman daftar pesanan dan detail pesanan.
- Menambahkan komponen status serta timeline pesanan.
- Mengembangkan halaman profil Student.
- Mengembangkan halaman wallet Student.
- Menambahkan authenticated API client untuk request yang membutuhkan access token.
- Menyempurnakan autentikasi, pengecekan role, dan pengambilan access token pada sisi client/server.
- Menambahkan service profil dan pengaturan redirect berdasarkan role.
- Menyesuaikan layout Student, Merchant, dan Admin.
- Menyesuaikan halaman utama dan Koperasi.
- Mengurangi penggunaan beberapa mock data karena data mulai terhubung dengan API.
- Menambahkan manifest, favicon, serta icon aplikasi untuk mendukung identitas aplikasi.
- Melakukan pengecekan build dan pengujian alur utama aplikasi setelah integrasi.

## Hasil

Pada akhir pengembangan Hari Ketiga, alur Student menjadi lebih lengkap mulai dari dashboard, katalog, keranjang, checkout, daftar pesanan, detail pesanan, profil, hingga wallet. Integrasi autentikasi dan komunikasi dengan backend juga dibuat lebih terstruktur melalui authenticated API client.

## Keterangan

Pengerjaan Hari Ketiga merupakan kelanjutan dari project SchoolCanteen yang telah tersedia sebelumnya. Pengembangan dilakukan dengan memanfaatkan source code/project lama sebagai dasar, sesuai ketentuan lomba yang memperbolehkan penggunaan project sebelumnya.
