## Progres Pengembangan

### Day 1 — Fondasi Frontend

Pada Day 1, pengembangan difokuskan pada pembuatan fondasi awal frontend dan struktur utama aplikasi SchoolCanteen.

#### Selesai Dikerjakan

* Inisialisasi project frontend menggunakan Next.js, TypeScript, dan Tailwind CSS.
* Membuat struktur utama aplikasi untuk role Public, Student, Merchant, dan Admin.
* Membuat layout awal dan navigasi untuk setiap role pengguna.
* Membuat komponen UI reusable untuk kebutuhan antarmuka SchoolCanteen.
* Membuat komponen awal e-commerce seperti product card, merchant card, dan category component.
* Mendefinisikan tipe data utama untuk product, merchant, user, order, wallet, pickup, dan withdrawal.
* Membuat struktur awal dashboard Student, Merchant, dan Admin.
* Menyiapkan route public untuk halaman kantin, koperasi, keranjang, dan detail produk.
* Menyiapkan arsitektur frontend untuk integrasi backend dan autentikasi pada tahap berikutnya.

#### Status Saat Ini

Fondasi frontend dan struktur utama aplikasi telah berhasil dibuat. Sebagian besar data pada tahap ini masih menggunakan data statis atau mock data dan belum terhubung langsung dengan backend API.

#### Belum Diintegrasikan

* Backend API
* Autentikasi pengguna
* Database
* Integrasi pembayaran
* Data transaksi real-time
* Alur checkout produksi

#### Pengembangan Selanjutnya

Tahap berikutnya akan difokuskan pada penyempurnaan halaman public commerce, interaksi keranjang, alur autentikasi, serta integrasi frontend dengan backend.

Dokumentasi lebih lengkap dapat dilihat pada [`docs/day-1.md`](docs/day-1.md).
